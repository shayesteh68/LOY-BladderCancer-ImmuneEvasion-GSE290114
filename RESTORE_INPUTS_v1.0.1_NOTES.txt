# Input restoration notes (reviewed with restore script 1.0.8)

restore_loy_inputs.sh restores or validates required input files for the GSE290114 workflow. It does not overwrite results/.

The script leaves restored files on disk and reports git status. It does not stage, commit, or push. Review the files and decide separately how to version them.

Run from the repository root with:
bash restore_loy_inputs.sh

The R environment name in environment.yml is loy-rnaseq.
